## 권장 작업 흐름

```
1. self-web UI 수정 (현재 폴더)
2. git commit → push (Bitbucket develop)
3. 백엔드 서버에 self-web 빌드 배포
4. MainActivity.kt base URL → 백엔드 제공 URL로 변경
5. APK 재빌드·설치 (URL 변경 시 1회)
6. 폰에서 UI 확인
```

UI만 수정할 때는 1 → 2 → 3 → 6 (APK 재빌드 불필요, URL 동일 시)
