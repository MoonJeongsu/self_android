## Phase 4 — AWS 이전 (1~2주)

**목표:** 로컬에서 검증된 구성을 AWS로 이전  
**Phase 2~3 성공 후에만 진행**

### 추천 AWS 구조

```
EC2 1대
 ├─ self-server (Tomcat + WAR)
 ├─ (선택) self-web 빌드물
 └─ (선택) self-admin 빌드물

RDS 1대
 └─ MySQL (selftest DB)

S3
 └─ 진단키트 사진 저장

(선택) CloudFront
 └─ self-web, self-admin HTTPS 배포
```

### 필요한 것

- [ ] AWS 계정 + 결제 설정
- [ ] EC2 인스턴스 (Java + Tomcat)
- [ ] RDS MySQL
- [ ] 보안그룹 (7080, 3306, 22, 443 등)
- [ ] 키페어 (.pem)
- [ ] (선택) 도메인 + SSL 인증서

### 이전 순서

1. RDS 생성 → 스키마·데이터 마이그레이션
2. EC2에 Java·Tomcat 설치
3. WAR 배포 + `context-datasource.xml`을 RDS 주소로 변경
4. self-web `nuxt build` → EC2 또는 S3+CloudFront 배포
5. axios baseURL → AWS API 주소로 변경
6. 동작 확인

### 완료 기준

- [ ] AWS URL에서 API·프론트 모두 접근 가능
- [ ] RDS에 데이터 정상 저장
- [ ] HTTPS 적용 (운영 시)

- 문서·시안 보고 요구사항 이해
